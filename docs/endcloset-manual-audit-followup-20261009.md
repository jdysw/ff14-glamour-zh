# EndCloset 手动汉化审计及补充（2026-10-09）

## 来源与样本
用户导出的 `zhx-manual-audit-v1`：6 个 EndCloset 页面，共 1,652 条文本及属性记录，229 条包含拉丁文字、日文或韩文。除正文语言外，至少包括 28 条韩文风格筛选标签、若干英文装备过滤标签、赞助说明、导航无障碍属性、图片标签与计数项。无原文基线（`baselines: {}`），不能计算真正的翻译成功率。原始导出含玩家作品，不存入公开仓库。

## 修改范围
- 样本中 28 个韩语风格词（主页 styleTags 类别）和装备列表中的英文过滤标签（`JobSet`、`Fur`、`Wrist gloves` 等）做精确替换，避免将文章正文当作 UI 翻译。
- 赞助页说明、支付方式、赞助款明细与相关提示使用自然中文；`Ko-fi`、`KakaoBank` 等品牌及实际账户标识不改写。
- 动态 `Showing X of Y items`、`Glamour Set <ID>` 的数量与 ID 保留不变；`primary` 仅在 NAV 标签的 `aria-label` 上译为“主导航”，避免误译其他语境。
- `작성자: <name>` 将固定前缀翻译为“作者”，保留作者姓名。
- 浏览器标题可翻译固定 `FF14 글래머 투영` 后缀，未知的玩家作品标题和未命中的装备名称保持原样。

## 明确保留
玩家创建的概念穿搭标题（例如 `차원의 방랑자`）、玩家昵称、版权商标行、站点品牌 `@end_Closet` 以及常用 FF14 等级标记 `LV`/`Lv.`，不计入确认漏译。

## 验证
对应新增用例位于 `tests/unit/test-endcloset.mjs`，包括字典、数量、图像、无障碍属性、作者提示、标题及保留原文负例。构建时 `dict/dict-endcloset.json` 是权威源；`src/core/dictionary.js` 已同步生成。待用户升级 PR 版本后，仍需在同 6 页面复测而不是直接宣称无遗漏。
