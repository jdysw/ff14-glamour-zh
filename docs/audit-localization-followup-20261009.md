# 七站实测后的汉化补充（2026-10-09）

源证据：[7 站在线审计](https://github.com/jdysw/ff14-glamour-zh/actions/runs/37927223245)；51 个有效页面，1635 次候选命中，944 条不同候选文本。**候选不代表经过人工确认的漏译条数**。

## 已处理

- **FF14-FC**：补充筛选重置、排行榜、站内导航、站点介绍、评论表单、基础属性与结构化提示等可靠短句；修正脚本自身生成的“一览・搜索”中日混排文案；补译 `title` / `aria-label` 及分类归档链接。对日文假名片段的兜底替换增加词边界防护，防止把 `メールアドレス` 误译成含“连衣裙”的文字，或破坏未知武器名。未知日文复合装备名不再半翻译。
- **FFXIV Collection（主站和 Weapon）**：补全分页、物品品级、菜单、职业名等，修复原先漏扫的 `aria-label`、`alt`、英文 `title`；仅在筛选器内汉化 yes/no、male/female；按已知套装名拼装图片替代文本；未知物品名保持原文。
- **Ronka**：翻译编辑器 `도움말` 和搜索按钮 `검색:`；保留韩文投稿标题和非官方截图说明。

## 不批量处理

原报告有大量站点作者文章、用户作品、站点品牌、版权、职业英文缩写、未知装备原名，以及跨页面重复候选。不能把全部 944 条原文直接写入词典，更不能把“误报变少”解释成完全翻译。对词典、适配器做分层修复，避免破坏已有装备术语映射。

Mirapri、Eorzea Collection、EndCloset、灰机 Wiki 在本轮访问时全部遭遇 Cloudflare/WAF 拦截，未取得真实页面 DOM，故没有声称补完其不可验证的内容。

## 验证

- `node tests/unit/test-audit-localization.mjs`：直接测试实际站点翻译函数和带原文的 DOM 属性桩（含未知武器名、邮箱地址、投稿保留的负例）。
- `npm ci && npm run build && npm test`：发布构建、全量单元与集成验证。
- 合并后建议再次使用实际浏览器复扫，从结果区分真实缺口和未翻译的文章正文。
