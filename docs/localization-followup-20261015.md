## 审计修正

- CLI 对精确品牌、版权、邮箱示例作豁免，中文句子中的已核实站名不再触发“部分翻译”；未知英文词如 `Settings` 仍会被报告。
- 广告推广链接及 `rel=sponsored` 作为广告上下文。未因普通 URL 出现商店名称而豁免。
- 日文纯汉字词按各站自己的词典判断，避免 Miramiru 的“染色→染剂”规则把其他站点正确的“染色”误报为遗漏。
- Ronka 投稿缩略图的替代文本属于玩家标题，保留原文并按玩家内容处理。
- 按钮的 `value="on"` 属于内部提交状态，不作为可见文案；正文、无障碍标签和输入式按钮的显示值继续采集。
- 浏览器审计升级为 **1.3.2**，沿用原安装文件名和脚本身份。

## 验证范围

Miramiru 先发现扫描 18 个公开页面／界面状态，再用 `tests/live/test-miramiru-followup.mjs` 检查三语的比赛、公告、统计、关于、支持、登录窗口与投稿须知，共 21 个样本。支持页补齐正文后单独复验三语；最终这些样本未发现审计器识别的 UI 残留。

FF14-FC 仍有部分装备系列、图片长说明中的名称不能完整解析，保留待核对，未据此编造国服名称。此前受 HTTP 403 阻断的站点也不能算作已完成线上验收。上述结果仅代表有界样本，不是整站覆盖率。

## 本地复验

```powershell
node build/build.mjs
node tests/run.mjs --suite=unit,integration
node tools/coverage/run-native-coverage.mjs
node tests/live/test-miramiru-followup.mjs
```

Windows 终端运行 Python 相关检查时应设置 `PYTHONIOENCODING=utf-8`，避免系统 GBK 输出编码导致 emoji／校验符号的编码错误。

`npm run build:miramiru-test` 生成内置最新数据的 1.4.5 测试脚本；更新后再配合审计 1.3.2 测试。正式数据尚未部署，PR 仍保留草稿。
