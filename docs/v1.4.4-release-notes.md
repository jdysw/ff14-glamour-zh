# v1.4.4 更新说明

本版本整合 [PR #44](https://github.com/jdysw/ff14-glamour-zh/pull/44) 的 Eorzea Collection (EC) 套装汉化、各站中文搜索交互与原生筛选兼容性修复。正式脚本版本统一为 `1.4.4`，包含现有全部受支持站点，不是单独的 EC 测试版。

## 主要更新

- **EC 套装与饰品中文化**：从国服装备英中对照聚类推导套装名称与职能变体；为实际核验的特殊套装、Hooded 衫款式、饰品套装及部位页补齐翻译。优先采用物品表中的正式译名；未获正式对应关系的可组合名称作为描述性译名，避免误称官方名称、叠加“套装套装”。
- **中文装备搜索与智能候选**：按 EC 页面部位限定候选范围，包括装备、饰品、鸟甲及面饰；支持套装中文检索、英文原站搜索；选择候选后立即收起浮层，站点原生选项可一次点击完成确认。
- **站点原生交互保护**：修复 EC vue-select 的点击事件被装备 Wiki 跳转拦截的问题，同时保护筛选、按钮及输入控件的原生交互；普通装备的灰机 Wiki 跳转仍保留。
- **EC 重置筛选**：针对 `/glamours/head/27832` 之类**把装备过滤条件写在 URL 路径中**的列表，重置时清除路径中的装备筛选段，而不是只删查询参数后刷新旧页面；`/glamours/tanks` 等非装备类别保留原路径。Gearsets、Accessories 的独立 Reset 入口亦兼容。
- **跨站兼容性**：同步调整 End Closet 等受支持站点的筛选控件避让逻辑、智能候选关闭行为，并新增独立测试版脚本以便定位站点问题。

## 验收范围

- EC 套装标题、详情 H1、套装卡片、智能搜索范围及边界；覆盖冬季与 Hoodie 等系列。
- 选择智能候选后隐藏中文列表，并确保不误打开灰机 Wiki；异步结果失效时不误选。
- 重置筛选不仅验证点击事件，还验证清除 URL 查询和物品筛选路径，新增对 `/glamours/head/27832` 的回归断言。
- 按仓库现有的 Build & Verify、Unit Tests、Integration A/B/C、CodeQL 等流水线验收。

## 使用说明

正式版与 PR44 各站测试版不要同时在同一个目标站点启用，以免重复注入。版本由 `package.json` 作为单一源，`build/userscript-header.txt` 同步 `@version`；正式发布依托 `.github/workflows/release.yml` 的 GitHub Release 自动化。
