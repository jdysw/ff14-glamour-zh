# xivc.app 接入说明

`xivc.app` 作为独立站点 id `xivc` 接入站点策略与注册表，并声明复用 `miramiru` 发布数据集、`items` / `dict` 表和 `nameMap` / `itemHash` 索引。站点 adapter 实现位于 `src/sites/xivc.js`。

脚本匹配使用 `https://xivc.app/*`。覆盖审计目前仅允许 xivc 根路径作为采集入口；在确认实际安全路由前，不接受深链。

适配器本地化固定界面标签和提示，并翻译页面上可识别的装备卡、已选槽装备名；`#item-search` 接入现有中文候选，提交时仍沿用站点原生筛选。已识别装备旁显示 Wiki 链接，目前只支持站点到 Wiki 的跳转，没有从 Wiki 反查到 xivc 的入口。不会改动预设值或卡片试穿交互。

2026-10-17 在独立 Chrome CDP 9335 实站验收：WebGPU adapter 可用，官网装备数据加载到 100%，装备网格显示 3,233 张卡片，画布中可见角色。输入“迷彩绒御敌军帽”后，中文候选指向 `AR-Caean Velvet Cap of Fending`；选择候选后站点搜索框保留英文，列表收敛到该装备。点击中文卡名会更新 Head 槽位；单独点击卡片 Wiki 链接不会触发试穿。卡片与已选槽的 Wiki 链接均可见，没有被装备名称裁切。

实站 observer 诊断中，中文搜索与选取后的累计计数为 9 次观察处理、55 个局部节点、105 ms，单次最高 44.9 ms；随后空闲两秒，计数没有变化。采样覆盖本次筛选和选择的 DOM 更新；它不是长时间性能基准。验收确认了 WebGPU adapter、角色画布、数据加载和原生槽位状态；没有独立确认特定装备模型最终渲染效果。

实站流程验证时发现 viewer 操作提示缺少中文词条，已补入词典；最终测试包已重建，并通过词典回归与 xivc 浏览器综合验证。

xivc 官网当前没有装备 URL 深链，因此这轮只支持从已识别的 xivc 装备卡/已选装备前往灰机 Wiki；Wiki 页不生成返回 xivc 的装备链接。未知装备不生成 Wiki 链接。审计器仍只接受根路径作为 xivc 采集入口，并清理 query/hash 中的站点参数。
