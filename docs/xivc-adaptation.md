# xivc 适配

<https://xivc.app/> 为浏览器角色试装工具。站点 id 为 `xivc`，复用 Miramiru 多语数据、items／dict 表和既有索引。

- 汉化固定界面、部位／外观选项、提示、已识别装备卡和选中装备，以及染色显示。
- `#item-search` 使用现有中文候选；提交英文原生查询，保留部位／种族限制和站点实际模型状态。
- 装备名旁追加独立 Wiki 链接；卡片仍用于原生试穿，Wiki 点击不触发选择。
- 区分装备、套装和染色模式，染色选择不弹装备候选，也不把色名当作物品链接。
- 处理搜索结果的纯文本／mark 高亮展示，保留父卡节点和原生事件；未知装备不猜链接。
- 预设名称、输入值、选择编码和原生保存／导入／导出功能不改写。

观察器限定在 UI 容器，按批次复用模式上下文并局部处理；不观察渲染视口与 FPS。字体由公共层提供。

目前只支持 xivc → Wiki；网站没有可用的装备定位深链，Wiki 页不生成返回 xivc 的装备链接。审计仅接受根路径并清空 query/hash，预设名称归用户内容，装备与外观选项分别复核。

## 测试

`npm run build:xivc-test` 生成独立内存词库测试包。综合回归覆盖中文候选与原生查询同步、卡片／Wiki 事件分离、染色隔离、节点复用和搜索高亮。

离线 DOM 回归不等同于 3D 模型视觉验收。发布前在支持 WebGPU 的浏览器复核代表性装备与原生操作；不能据一件装备推定所有种族、组合和模型均已验证。
