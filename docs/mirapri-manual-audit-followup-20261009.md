# Mirapri：9 页真实浏览器审计与补充（2026-10-09）

- 证据来源：用户本地浏览器导出的 `zhx-manual-audit-v1`；9 页、2,650 条文本/属性记录、无原文基线。原始导出包含玩家昵称及作品数据，未公开提交。
- 有效页面：首页、3 个详情、时尚品鉴、投稿指南、关于本站、联系我们、发布幻化。
- **根因 1**：Mirapri 适配器原先将被翻译文本的日文原文重新写入 `title`，产生大量日文 hover 残留。已改为只保留 `data-zhixia-source-text` 供诊断。
- **根因 2**：`alt`/`title`/`aria-label` 没有进入属性翻译；现在只翻译白名单 UI，异步属性更新也能复译；用户填写的 `input.value` 不受影响。
- **根因 3**：投稿指南和网站简介为静态文案，原词典缺失。按原文精确映射逐段翻译，不把用户作品名或玩家评论当作通用 UI 字典。
- **根因 4**：联系表单字段、提交确认和图片轮播提示不完整，已补齐。
- 对首页卡片作品标题、图片描述等作者内容仅在明确作者 DOM 区域避让；不尝试猜测玩家作品名或装备名。
- 回归测试：`tests/unit/test-mirapri-manual-audit.mjs` 及更新后的 `tests/integration/test-mirapri.mjs`。旧集成断言“必须显示日文原文 title”与新审计确认的 bug 相矛盾，现改为真实可用性要求“不得合成未翻译的日文 hover 标题”，并保留其他真实功能断言。
- **限制**：没有先前原文基线和新版本复扫，不能据此宣称 100% 汉化。
