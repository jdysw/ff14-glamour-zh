# Miramiru 三语接入

适配对象：日文 <https://miramiru.co/>、英文 <https://miramiru.co/en>、韩文 <https://miramiru.co/ko>。页面结构采样于 2026-10-14。

- 英／日／韩界面、职业、种族、装备部位、获取来源类别与染剂名称显示中文。
- 装备名使用物品表的英／日／韩索引翻译，详情页优先通过 Lodestone hash 定位国服物品名。
- 只改写 `a.eorzeadb_link` 装备主链接到灰机 Wiki，保留节点结构、官方来源详情链接和 `/en/items/<id>` 同款穿搭入口。
- 使用统一观察器补翻译异步内容、属性和 React 复用节点；数据就绪与 bfcache 恢复时补扫。
- 不转换搜索输入值，不翻译评论输入和可编辑内容。中文搜索不在本次范围内。
- 未识别的装备、作者创作的自由文本及尚未收录的副本来源保持原文，不猜测译名。

词典源为 `dict/dict-miramiru.json`，经现有生成器注入内嵌兜底并打包远程词库。新增 V3 站点文件为 `miramiru/{names,hash,alias,dup}.tsv`，生成英／日／韩名称索引。

## 独立测试脚本

运行 `npm run build:miramiru-test` 生成 `dist/ff14-miramiru-zh-1.4.5-test.user.js`。

在 Tampermonkey 或 Violentmonkey 的导入／安装文件功能中选择该文件，然后打开 <https://miramiru.co/en>。测试版使用独立脚本名称与 namespace，仅在 Miramiru 运行；内置本次生成的压缩 V3 数据快照，不请求未上线的数据、不读写正式版 GM 缓存，也不写 localStorage。修改适配器或词典后需重新生成测试脚本。正式版支持上线后请停用测试版，避免两个脚本同时处理页面。PR 的 Integration B 检查成功后，也可下载 `miramiru-test-userscript` 工件；生成产物不提交到源码仓库。

## 发布边界

本次 PR 版本为 1.4.5，不自动部署或创建 Release。

正式使用需同步发布支持 Miramiru 的脚本和 V3 数据；在线验收预置了本次生成的数据，不能据此声称生产数据站已支持新站。

旧版脚本严格校验站点清单和词典层名，会拒绝新增站点／词典层的数据包。因此发布前需要确定旧版兼容分发或升级迁移策略，不能将本次扩展数据单独覆盖到生产数据站。现有 V3 文件路径与缓存格式没有更改。

## 三语补齐与审计（1.4.5 后续修订）

Miramiru 数据现在同时包含英、日、韩名称，动态切换语言后无需改回英语。UI 词典以站点三语 locale 的同名键核对，补齐菜单、筛选、部位、职业、染剂及数量文案。三种语言的真实装备详情已使用独立测试安装脚本验收。

配套浏览器审计脚本升级至 1.3.0，沿用原有安装文件和脚本身份；增加 Miramiru 域名、快照语言、玩家内容／装备分类以及三语基线、配对和导出回归。CLI 审计也登记了三语入口。

## 中文字体统一

Miramiru 原有正文优先使用 LINE Seed JP／Noto Sans KR，标题另用 Lexend。脚本在 Miramiru 内统一采用简体中文字体优先的本地字体列表：Windows 优先微软雅黑 UI／微软雅黑，其他设备按可用字体回退至苹方或思源黑体等。无需新增字体下载。

标题、正文、输入框及动态弹层共享字体；保留字号、粗细、SVG 图标与代码等宽字体，不修改原页面语言属性。字体规则已移入共用层，为全部支持站点启用，见 [共用字体说明](shared-chinese-font-20261015.md)。真实英／日／韩页面检查了计算字体及实际汉字所用的平台字体，并确认无新增横向溢出。
