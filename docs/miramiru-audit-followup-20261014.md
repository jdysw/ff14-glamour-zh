# Miramiru 用户实测审计补漏

输入为审计 1.3.0 的十份英文页面状态快照：收藏、关于、FAQ、首页、排行榜及周排行、统计页三个周期、公告页。全部采集成功，没有人工原文基线，不能据此计算完整汉化率。

最初共有 89 次疑似命中、59 个不同候选。其中站名 20 次、版权行 10 次属于应保留的固定文字；其余候选需要结合页面作用域及站点原始词条判断，不能直接视作 59 处确认漏译。未知区域中也有真正的固定说明漏译，不能只处理 UI 标题而忽略这些段落。

## 修订

- 根据网站原始三语 locale 的同名键补齐 133 组消息及相应渲染片段，覆盖徽章与头像框说明、关于页、FAQ 问答、统计标题和操作入口。
- 补齐已核对的公告标题；公告摘要及正文仍按内容文案复核，不承诺任意新文章自动翻译。
- 支持富文本拆分标题、多行说明的空白归一化，以及带数量的官方标签；无官方标识的玩家标签不按此规则转换。
- 汉化测试版仍为 1.4.5；审计脚本升级为 1.3.1，精确豁免站名和版权，识别静态说明的 UI 作用域，保留玩家内容默认脱敏。
- 原始导出文件及玩家内容不进入仓库。回归夹具仅包含已核对的公开站点固定消息。

## 验证

完整构建、40 项单元测试、39 项原生源码测试通过；Miramiru 三语夹具、独立安装脚本、审计基线与导出回归通过。使用生成的独立安装脚本对英文关于、FAQ、收藏、统计、公告五类真实页面验收通过。

这些结果证明上述固定文案的修订，不代表已重新扫描所有页面或达到整站零漏译。
