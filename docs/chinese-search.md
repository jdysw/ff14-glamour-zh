# 中文装备搜索

中文候选只接管已识别的装备检索框，不处理玩家、作者、评论、预设名称和一般文本输入。没有明确译名时保留原站行为。

## 操作与范围

- 输入中文和输入停顿不会自动提交搜索；点选候选、回车或原生搜索按钮按站点能力转换查询。
- 正式译名和别名支持包含匹配，按头、身、手、腿、脚、其余分组，同组保持匹配相关度；候选分批呈现。
- 输入法组合态不转换；触屏滚动、键盘选择和视口变化保持可用。
- 通过原生 value setter 和 input／提交事件同步站点状态，保留有效筛选；未知或不明确的查询不擅自跳转。
- EC Vue 控件、Eden 和 xivc 保留原生查询值，避免定时把显示改回中文而破坏受控模型。

| 站点 | 当前行为 |
| --- | --- |
| Mirapri、FF14-FC、FFXIV Collection | 沿用原站表单、部位与筛选 |
| Ronka、End Closet | 转成站点所需韩文查询，保留原生列表筛选 |
| Eorzea Collection | 表单和 Vue 输入按页面／控件分类，套装查询不伪造成详情链接 |
| Mirapri Eden | 首页按日文、制作器按实际显示语言查询；候选提交原生控件 |
| xivc | 装备／套装检索使用原生英文，染色模式不弹装备候选，原生部位和种族限制保持 |
| Miramiru | 当前没有接入公共中文搜索；保留网站原生输入行为 |

## 数据和分类

仅明确允许的可幻化物品进入候选，未知类别不凭译名猜测。别名不绕过分类。EC 的面饰、鸟甲、饰品、部位和套装规则见 [分类范围](ec-smart-search-scopes.md) 与 [套装目录](ec-gearsets-catalog.md)。

动态重建输入框或装备节点后，仍需保持原生模型、Wiki 目标和候选范围一致；不能根据中文显示文本反写站点内部枚举。

默认回归覆盖候选、输入法、触摸／键盘、原生事件、范围隔离、未知项和节点复用。发布前按实际站点复核代表性检索；访问失败不能视作功能验收成功。
