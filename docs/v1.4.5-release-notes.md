# v1.4.5 — 第一阶段：可靠性、测试及发布治理

本版本基于 v1.4.4，聚焦功能边界和发布链可靠性，不改变既有七站适配范围和 V3 远程数据格式。

## 功能修复

- **中文装备搜索表单识别**：作者、玩家、标题、评论等非装备字段始终排除在候选外。单字段表单也不会因兜底路径而误转换中文输入；合法的独立搜索框仍保留兼容兜底。
- **HTTP 请求超时**：无论 fetch 返回响应头有多快，都必须在读取完整响应体后才清理超时。响应体停滞时触发 abort；无法创建 AbortController 时仍能让调用方按时获得超时错误。GM_xmlhttpRequest 路径不变。
- **MutationObserver 调度**：持续洪峰最多重排一次 timer；超容量的 childList、attributes、characterData 队列合并为一次观察根补扫，避免队列持续增长和任务无限推迟。销毁后取消定时器与待处理队列。
- **V3 数据刷新**：显式 invalidate 后重置就绪状态，允许已订阅的站点和中文搜索收到新一代 ready 通知；串行处理先后两代加载，使用 generation guard 防止过期响应覆盖新索引。

## 工程与交付

- CI 将 `integration/test-ec-search-inline.mjs` 纳入实际运行的 Integration B 组。
- 新增 HTTP / V3 刷新回归测试，增加单字段搜索、持续 DOM 洪峰、字符队列超限与 disconnect 行为测试。
- Release 只接受 `main` 的 push/manual 触发，在创建 tag 前按**同一 commit SHA**等待完整构建、单元、集成、CodeQL 和 SonarCloud 检查通过；过期 commit 不发布，同版本指向不同 SHA 时明确报错。
- 发布使用 `--target` 指定经验证的提交，避免 tag 跟随移动中的分支头。

## 测试约束

回归测试模拟真实异步时序，不以同步立即执行的 `setTimeout` 假实现代替浏览器计时语义。若测试发现确实不符合行为契约的实现，应修复业务代码，而非放宽预期。

## 未纳入本版

中文搜索倒排索引、EC 分类常量外置、核心模块循环依赖消除、全面覆盖率治理与七站真站人工覆盖审计属于后续阶段，不在本次 PR 中改变。
