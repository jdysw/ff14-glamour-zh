# Mirapri Eden 适配

站点 <https://mirapri.ff14eden.work/> 使用 Vue 2 / Vuetify 和 hash 路由，提供日文／英文界面。

- 翻译固定界面、筛选／标签、排行榜、制作器和内嵌编辑器的菜单、提示及静态输入属性。
- 玩家标题、正文、署名、画廊介绍与输入值保持原样，不改变 Vue 枚举或 Canvas 像素。
- 装备名称和官方物品链接支持 Wiki；筛选、原生选项和制作器操作继续由站点处理。未知项不猜链接，节点复用时更新或清理旧目标。
- 中文搜索只绑定首页、画廊和已识别装备框；首页提交日文，制作器按实际显示语言提交日文或英文。实际查询和控件状态保持一致。
- Wiki 物品页可按已知日文名打开 Eden 的原生搜索入口。

Eden 复用 Miramiru 多语数据集，界面词条使用 main 层的 `eden:` 前缀，不增加发布数据集或词典层。

## 图片投稿的装备清单

原站公开 `/glamour/all_users_glamour.json` 中的 `equipments[].name` 和 `colorNames` 是搜索依据，并非 OCR。标题、正文和作者等文本也可命中；清单缺失且名称只在图片里时，原生搜索无法识别它。

打开作品或画廊详情后，按图片 origin + pathname 匹配记录，在原图和正文下方生成中文装备／染色清单，已识别装备提供 Wiki 链接。多图共享记录；完全相同的装备／染色行去重，不同染色保留。冲突记录、未知名称和无数据状态均明确显示。

只在打开可匹配弹窗时读取公开数据，优先复用原站资源时间戳和浏览器缓存，单页请求合并。内存索引仅保留图片键、装备与染色，不持久化玩家信息。失败可手动重试；切图、关闭和迟到响应不能残留旧链接。

DOM 批次按祖先去重，投稿面板每批统一同步。窄屏弹窗整体滚动，关闭操作保持可用。

## 测试

`npm run build:eden-test` 生成独立测试包，内置当前 V3 快照，仅在 Eden 运行且只使用页面内存缓存。回归覆盖原生搜索、编辑器／表单提示、用户内容保护、装备复用、切图、迟到响应、染色和失败重试。

测试版与正式版身份不同；发布后停用相应测试版。审计识别公开 hash 路由并去除查询值，账号和未知路由不采集。
