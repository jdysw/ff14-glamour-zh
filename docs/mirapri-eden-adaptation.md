# Mirapri Eden 适配

站点为 <https://mirapri.ff14eden.work/>，调查于 2026-10-17。Vue 2 / Vuetify，页面使用 hash 路由；本站只发布日文、英文消息表，浏览器其他语言会回退到已有语言。

- 翻译日／英固定界面、菜单、种族与性别筛选、排行榜、制作器（含内嵌图像编辑器工具与 tooltip）、染剂工具及显示属性。表单提示属性可翻译，输入值与投稿内容保持原样。约 590 条独立前缀词条存于 `dict-main.json`，不覆盖 MIRAPRI SNAP 的同名文案。
- 玩家投稿标题、正文、署名、画廊介绍和填写内容不翻译；不修改隐藏筛选值、Vue 数据或 Canvas 内容。制作器画布及上传图片中的文字不是 DOM 文本，保持站点原有绘图结果。
- 排行榜和表格装备名称及官方物品链接支持灰机 Wiki。原生筛选按钮、复制按钮、下拉装备选项继续由站点处理；未知装备不猜测跳转，Vue 复用节点时清理旧目标。
- 中文搜索使用现有候选、回车与原生 input 事件，仅绑定首页、个人画廊和已识别的装备搜索框。Vue 控件使用转换后的日文查询，不定时把显示值改回中文，防止 DOM 与搜索模型失配。标题、备注、账号和只读筛选框不接管。
- 无装备记录时，原站搜索仍可匹配作品标题、正文、用户等字段，但不会通过 OCR 搜索图片像素中的装备名称；名称只出现在图片内时无法命中。
- Wiki 增加 `/#/?search=<日文装备名>` 反查入口，使用内嵌站点图标。
- Eden 的 `dataSite=miramiru`，复用现有多语索引及缓存；首页优先提交日文名，制作器按实际装备显示语言提交日文或英文。`DATA_POLICIES` 描述八个数据集，`SITE_POLICIES` 描述九站界面；现行 V3 清单与八层词典格式不变。
- 审计工具 1.3.4 支持 Eden，保留 hash 路由的页面身份并去除查询值；账号、个人设置及未知路由不采集。

## 图片中的装备名称

原站的作品图片可能已将装备名称绘制进像素，但搜索使用公开投稿 JSON 中的 `equipments[].name` 和 `colorNames`，而非图片识别。数据地址为 `/glamour/all_users_glamour.json`；调查快照有 7,409 篇投稿，其中 6,088 篇含装备记录。这是一次页面调查结果，不是固定覆盖率。

打开首页作品或个人画廊的详情弹窗后，在原图和投稿正文下方生成「投稿装备清单」，匹配已知国服名称并生成 Wiki 链接，附原生名称与染色。图片像素、作者文字和原站 Vue 数据均不改写。窄屏弹窗整体可滚动，关闭按钮保持可见。

匹配采用原站同样的图片 `origin + pathname`，忽略尺寸和格式查询。多图投稿共享同一清单；同图装备记录冲突时不生成猜测链接。无装备数据、未知名称、网络失败均保留明确状态；未知装备显示原名而不链接。换图、关闭弹窗及迟到响应不能残留上一件装备的目标。

只在实际打开可匹配弹窗时读取公开投稿数据。优先复用原站已完成的时间戳请求及浏览器缓存，单页请求合并；失败只在手动重试时重新读取。内存索引仅保留图片键、装备名和染色，不保存用户名、投稿标题或正文，不写入 GM/localStorage。测试版不内置这份动态投稿数据。

测试并入已有 Eden 浏览器场景和原生站点测试，覆盖迟到响应、切图、不同染色、无数据、未知名称、点击目标和重试。Happy DOM 仅作为开发测试依赖，用实际 DOM 选择器和节点替代手写 CSS 模拟，不进入 userscript 产物。

性能路径将一次观察回调中的变更节点按祖先去重，再对合并后的局部根扫描，并在扫描完后统一同步投稿面板；V3 names 文件的一次拆行同时构建名称、候选策略和装备分组索引。本机脚本采样中，maker observer 批次约从 59.2ms 降至 18.4ms，排行榜 observer 批次约从 5.5ms 降至 3.5ms，排行榜脚本初始化约从 336ms 降至 208ms；这些是该环境的脚本测量，不代表全页加载时间。

验证包括现有源码回归、Eden 一份综合浏览器夹具、Wiki 现有集成场景和实际站点观察。实际搜索“小牛皮骑手外套”转换为日文，原站数据加载后返回 21 条搭配；排行榜可见装备与目标 Wiki 匹配。原站初次请求曾失败，使用原站只读加载方法重试后完成验证，未更改服务端数据。

测试版：`npm run build:eden-test` 生成 `dist/ff14-eden-zh-1.4.5-test.user.js`。仅匹配 Eden，数据内置且缓存限于当前页面内存，无需改动已发布的数据站；与正式脚本使用不同安装身份。当前仍保持开发基线版本 1.4.5，不覆盖已发布的 v1.4.5 发行件；新正式发行须使用新版本号。
