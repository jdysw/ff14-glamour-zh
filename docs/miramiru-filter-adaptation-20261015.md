# Miramiru 筛选选项与官方标签

本次按网站实际前端枚举核对 83 项三语选项：14 个装备部位、13 类来源、8 个种族、8 类染色、33 个职业及 7 个职业分组。补齐显示译名、下拉选项、颜色 aria-label、装备搜索占位符和筛选结果摘要。

职业按钮仅在筛选面板中将缩写替换为中文简称，原有提示继续显示完整职业名，不将普通页面上的英文缩写统一改写。原站按钮尺寸和事件不变。

对公开标签接口返回的 28 个官方标签建立明确对照，支持候选列表、已选标签、数量提示，以及英文、日文、韩文的官方标签标记。对原站默认前十项之外的官方标签，也能按已核实名称识别。未知标签和用户自定义标签不自动猜译。

所有转换只影响文字和提示，不改变输入值、选项编码、标签 slug、链接目标或 React 回调使用的名称。
